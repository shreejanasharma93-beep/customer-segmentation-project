 Customer Segmentation Project

Project Overview

This project performs customer segmentation using the K-Means Clustering algorithm. Customers are grouped based on their Annual Income and Spending Score to identify different customer segments.

Objectives

* Analyze customer behavior
* Segment customers into groups
* Visualize customer clusters
* Generate business insights

Features

* Customer data analysis
* K-Means clustering
* Cluster visualization
* Customer segment identification

Tools Used

* Python
* Pandas
* Matplotlib
* Scikit-learn
* Streamlit

Dataset

The dataset contains:

* Customer ID
* Age
* Gender
* Annual Income
* Spending Score

Project Output

![Customer Segmentation](screenshot.png)

Results

The K-Means algorithm successfully divided customers into multiple segments based on spending behavior and income levels. These segments can help businesses create targeted marketing strategies.

How to Run

1. Install required libraries:

   ```bash
   pip install pandas matplotlib scikit-learn streamlit
   ```

2. Run the Streamlit dashboard:

   ```bash
   streamlit run app.py
   ```

3. Open:

   ```
   http://localhost:8501
   ```
